## 🎯 WHAT IS THIS?

A **Google Sheets CMS** lets you edit your website content in a simple spreadsheet.

**How it works:**
1. You edit text in Google Sheets (like Excel)
2. Your website reads from the sheet
3. Changes appear instantly on your website

**No coding needed!** Just type and save.

## ✅ STEP 3: Make Sheet Public

This lets your website read the content.

### 3.1 Click "Share" (top right)

### 3.2 Change Permissions
1. Click **"Change to anyone with the link"**
2. Set to **"Viewer"** (they can only read, not edit)
3. Click **"Done"**

### 3.3 Get Your Sheet URL
1. Click **"Share"** again
2. Click **"Copy link"**
3. **Save this link somewhere!**

**Your link looks like:**
```
https://docs.google.com/spreadsheets/d/ABC123.../edit?usp=sharing
```

---

## ✅ STEP 4: Get CSV URL (For Website)

Your website needs a special URL to read the sheet.

### 4.1 Convert Your Link

Take your sharing link:
```
https://docs.google.com/spreadsheets/d/ABC123.../edit?usp=sharing
```

Change it to this format:
```
https://docs.google.com/spreadsheets/d/ABC123.../export?format=csv
```

**Just replace:**
- `/edit?usp=sharing` → `/export?format=csv`

### 4.2 Test Your CSV URL
1. Paste the CSV URL in your browser
2. It should download a CSV file
3. If it works, **save this URL!**

## 🆘 TROUBLESHOOTING

### Changes Not Appearing?

1. **Wait 2-3 minutes** - Google Sheets has a small delay
2. **Clear browser cache** - Press Cmd+Shift+R (Mac) or Ctrl+Shift+R (Windows)
3. **Check the sheet is public** - Anyone with link can view
4. **Verify the CSV URL** - Open it in browser, should download file

### Website Shows Old Content?

1. Check you're editing the right sheet
2. Make sure you pressed Enter after editing
3. Try opening in a different browser
